I/TD Shell 1.1.0 · live preview

Test build 2026-11-24 · simulated: no files, programs or Windows settings are touched

Windows desktop (simulated) The shell is minimised. Click I/TD on the taskbar to bring it back.

On a phone the preview is tiny: rotate the screen or use Fullscreen. It is built for a desktop and a mouse.

What's new in 1.1.0

  • Own taskbar. An AppBar strip with the live list of Windows windows, updated by system events instead of polling.
  • Notification area on the I/TD taskbar. Real app icons with tooltips; left, right and double clicks reach the app. Past eight icons, the oldest fold behind the chevron by the clock.
  • Lock screen with a PIN. Salted hash, a growing pause after five wrong tries.
  • Win key opens Start through the small native helper, itd-native.exe.

Try this

  • Alt Space: search palette. Ctrl Alt Space or I/TD: Start menu.
  • Ctrl 1…5: Desk, Programs, Projects, Files, Look; sections open as windows you can drag, snap and resize. Inside the shell, Ctrl K also searches.
  • Click Figma on the taskbar: the imtrtd design system opens for review, with the four accent themes and a token inspector. Explorer, Telegram and tray apps open minimal windows; drag, resize, double-click a title to maximise.
  • Right-click a tray icon, double-click to open its window, press + Tray until the chevron appears.
  • Set a PIN in 05 Вид → Поведение, then Lock. Five wrong PINs start the pause.
  • Accent, wallpaper and fonts in 05 Вид stay in this browser. Reset clears them.

The interface is the shell's own code, in Russian, as on the desktop. Only the bridge to Windows is replaced: disks, apps and windows are made up.
