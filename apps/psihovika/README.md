# TrueSightPsy

TrueSightPsy — русскоязычный каталог психологических методик с акцентом на психоанализ и психотерапию. Здесь можно изучать методики, проходить опросы и просматривать свою историю.

## Local development

```bash
npm ci
npm run dev
```

История и ответы пользователя хранятся в браузере. Локальный сервер доступен по адресу `http://localhost:8080`. Для некоторых функций нужны локальные настройки; не добавляйте пароли и строки подключения к базе в Git.

## Project areas

- Каталог и данные: `src/data/`
- Прохождение опросов: `src/components/runner.tsx`
- Личная история: `src/routes/history.tsx`
- Вход и подсчёт результатов: `src/lib/`
