# psy

Каталог психологических методик. Русский язык, акцент на психоанализ и психотерапию.

Админка: зарегистрируйтесь на `/login`, создайте команду на `/team`, затем `/admin`.

## Запуск

```bash
npm --prefix apps/psihovika ci
npm --prefix apps/psihovika run dev
```

Сайт открывается на порту 8080.

## Что уже есть

- 115 методик, фильтры по теме, школе и длительности.
- У каждой методики три глубины: **Касание**, **Разбор**, **Глубина**.
- У публичных шкал официальный подсчёт только на полном разборе. Короткий срез пороги шкалы не применяет. Четыре последних вопроса глубины в балл не входят.
- Кабинет: история, итог, диаграммы, промпт для ИИ, отложенные. Ответы лежат в браузере, не на сервере.
- Вход: кнопка Google и форма только для почты `@gmail.com`. Выход — в кабинете.

## Куда смотреть

- Каталог: `src/components/catalog-view.tsx`, данные в `src/data/`.
- Прохождение: `src/components/runner.tsx`, глубины в `src/lib/depth.ts`.
- Кабинет: `src/routes/history.tsx`.
- Вход: `src/routes/login.tsx`.
- Подсчёт: `src/lib/scoring.ts`.

Не переписывать `src/lib/auth/server.ts`. Почта с паролем включается только флагом в `src/lib/auth/email-password.ts`.
