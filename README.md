# I'm Trying To Design

Здесь собраны проекты студии I'm Trying To Design: сайты, инструменты для работы с текстом и творческие эксперименты. У каждого приложения есть свой README с инструкциями по запуску.

## Проекты

| Проект | Папка | Описание |
| --- | --- | --- |
| **HQ** | [`apps/hq`](apps/hq/README.md) | Сайт студии на Astro |
| **Studio** | [`apps/studio`](apps/studio/README.md) | Сайт и рабочее пространство студии |
| **Portfolio** | [`apps/portfolio`](apps/portfolio/README.md) | Портфолио на React и Vinext |
| **Cuebox** | [`apps/cuebox`](apps/cuebox/README.md) | Библиотека для заметок и повторного использования промптов |

| **TrueSightPsy** | [`apps/psihovika`](apps/psihovika/README.md) | Каталог психологических методик |

## С чего начать

Приложения развиваются независимо друг от друга. Выберите нужную папку, установите зависимости и запустите команды из README внутри неё. Большинству проектов нужны Node.js и npm; требования могут отличаться.

Например, запустить сайт Studio можно так:

```bash
npm --prefix apps/studio install
npm run dev:studio
```

Для некоторых приложений понадобятся локальные настройки или доступ к внешним сервисам. Храните их в локальных файлах, которые не попадают в Git, и не добавляйте в репозиторий секреты и личные данные.
